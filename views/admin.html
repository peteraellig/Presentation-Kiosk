Actions

Press the four outer corner keys together to unlock or lock the Stream Deck. On the Stream Deck Original, pressing any three corner keys together is enough to toggle the lock. Release all pressed keys before repeating. A single corner key selects its program on release. Dim keys indicate locked input.

Button configuration

Red buttons need a second tap on the remote (protection against accidental presses). Use "\n" in a label for a line break.

Slideshow timing

Choose 1–10 seconds per image (default 3). The next time this folder is selected, the screen and OMT output use this timing for buttons, API calls and scheduled playback. A single image stays on screen.

API access

This computer (localhost) is always allowed. Ranges are written like 192.168.1.0/24. Example call: http://<server-ip>:53101/api?Function=bild1

OMT output

Sends the presenter picture and sound as OMT (video + audio) to the network, for example to the SDI Converter. The sound does not go through the Windows audio output.

Chrome · No sound? / Kein Ton?

Deutsch

Damit der Ton in deinem normalen Chrome-Tab auch nach einem Refresh startet, braucht die Kiosk-Adresse eine dauerhaft gespeicherte Tonfreigabe.

So setzt du sie einmalig im Chrome-Profil auf dem Präsentations-PC:

  1. Öffne chrome://settings/content/sound.
  2. Klicke unter „Wiedergabe von Ton zulassen“ auf „Hinzufügen“.
  3. Trage die Adresse des Präsentationsfensters ein, zum Beispiel http://192.168.1.113:53101.
  4. Lade den Präsentationstab mit F5 neu.

English

To play sound automatically after a refresh in a regular Chrome tab, save a sound permission for the kiosk address.

Set it once in the Chrome profile on the presentation PC:

  1. Open chrome://settings/content/sound.
  2. Under Allowed to play sound, click Add.
  3. Enter the address of the presentation window, for example http://192.168.1.113:53101.
  4. Press F5 to reload the presentation tab.

Dual monitor? Move the running presentation window to the other monitor with Shift+Windows+←/→.
