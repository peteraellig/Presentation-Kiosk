How it works

The API switches the content on the presentation screen with a simple HTTP request. No login is needed, but access can be limited to certain IP addresses in the admin page (card "API access").

Base address of this server:

Format (GET request):

/api?Function=command

The command is not case sensitive. It works from a browser, Bitfocus Companion (HTTP GET), vMix, curl and similar tools.

Commands

Set the time per image in Admin → Slideshow timing (1–10 seconds, default 3). API commands and buttons use the same folder setting. Select the folder again to apply a change. Folders with multiple images loop; a single image stays on screen.

Function=What it doesButton nameTest URL

The "Button name" column shows which button of the remote page uses the same content. A dash means the content is not assigned to a button at the moment.

Answer of the server

Success (HTTP 200):

{"status": "ok", "selected": {"src": "bild1/", "type": "slideshow"}}

Errors:

HTTPMeaning
400Unknown command in Function=
403API is switched off, or the IP address of the sender is not on the allowed list
